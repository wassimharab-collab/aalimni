# علمني (Aalimni / 3allemni)

Tutoring marketplace PWA for the Tunisian market — bilingual Arabic/French, teacher search by location, subscription & payment simulation.

Static build, no build step required: plain ES modules loaded via an import map (React 18 from jsDelivr's ESM CDN), Leaflet for the interactive map (CSS/images vendored locally in `vendor/`).

## Deploy

This repo is served as-is by GitHub Pages (root of the default branch). Nothing to build.

## Local preview

Serve the folder with any static file server, e.g.:

```
npx serve .
```
